[FULL DESCRIPTION]
DataFlow Studio v4.0 is a high-performance desktop production suite engineered for media producers, studio editors, event photographers, and enterprise videography teams. Designed to eliminate bottlenecks in high-volume post-production workflows, DataFlow Studio unites lightning-fast media ingestion, intelligent file segregation, multi-camera synchronization, and automated Excel report fusion into an elegant, unified pipeline.

Built from the ground up for Windows 10 and Windows 11, DataFlow Studio combines a 32-thread parallel worker engine with strict atomic filesystem operations to handle terabytes of 4K/8K footage and high-resolution RAW photo captures with zero data corruption risk.

KEY CAPABILITIES:
- STAGE 00 • PV SEPARATOR: Instantly ingest mixed media dumps and atomically bifurcate photos (JPG, CR2, CR3, ARW, NEF, DNG) from video files (MP4, MOV, MXF) in milliseconds.
- STAGE 01 • UPLOAD STRUCTURE: Automatically construct standardized, clean production directory trees tailored for studio archive standards.
- STAGE 02 • PHOTO STATUS TAGGER: Synchronize camera photo rosters with master event manifests, detecting missing frames and matching capture sequences.
- STAGE 03 • REMAINING SHIFTER: Filter out unselected, auxiliary, and overflow media files into dedicated staging pools with atomic speed.
- STAGE 04 • EVENT IMAGE DISTRIBUTOR: Intelligently categorize and distribute master reference photographs across sub-events using smart abbreviation indexes.
- STAGE 05 • MULTI-CAMERA VIDEO TRANSFER: High-throughput 8 MB chunk streaming engineered for high-bandwidth cross-drive NVMe/SSD data transfers.
- STAGE 06 • THUMBNAIL SHIFTER: Isolate lightweight thumbnail proxies and preview files from master raw captures to accelerate cloud upload pipelines.
- STAGE 07 • DEEP-STYLE EXCEL FUSION: Integrated Python openpyxl engine that merges disparate camera manifests, preserving font styling, cell borders, fills, and formulas with 1:1 fidelity.
- STANDALONE TOOLS: Compound extension cleanup (.CR3.jpg to .jpg), video thumbnail suffix taggers (_V), and pre-flight storage headroom safety probes.

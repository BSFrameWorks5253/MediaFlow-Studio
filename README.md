## 🎬 Introduction

**MediaFlow Studio** is a deterministic, offline-first media orchestration platform built for professional event photographers, wedding cinematographers, and multi-camera production teams. It automates massive ingestion cycles—segregating raw formats, pairing attendee captures into individual client folders, routing event badges, fusing multi-sheet Excel balance logs, and consolidating inventory spreadsheets.

Unlike generic file managers, MediaFlow Studio operates with **zero accidental data loss**: every shift operation includes pre-flight disk headroom checks, dry-run simulation mode, and atomic reversible rollback manifests.

## 🚀 Key Feature Modules

### 1. 📂 PV Separator (Photo & Video Segregation)
* **Instant Atomic Renames**: Separates mixed photo and video shoots in seconds on same-drive volumes without slow duplicate copies.
* **Storage Headroom Safety Probe**: Pre-checks target volume free space before executing cross-drive migrations.
* **Format-Specific Filtering**: Accurately classifies `.cr2`, `.cr3`, `.nef`, `.arw`, `.jpg`, `.mp4`, `.mov`, and `.mxf`.

### 2. 🔍 Photo Matcher & Client Folder Injector
* **Batch Auto-Rename**: Renames unorganized camera shots with standard client numbers and sequence prefixes.
* **Two-Path Auto Matching**: Compares source dumps against final delivery subfolders with real-time diff preview.
* **Suffix Appending**: Automatically tags clean photos with `-P` and video thumbs with `-V` for delivery compliance.

### 3. 🎯 Event Image Shifter (Fixed Badge Distribution)
* **Permanent Reference Directory**: Asks once on first opening to set your master event images folder (`Q.jpg`, `M.jpg`, etc.) and permanently locks the path in configuration until modified from Settings.
* **Token Matching Engine**: Detects abbreviation markers in folder names (`_Q_`, `_M_`, `_Z_`) and copies corresponding badges automatically.

### 4. 📊 Excel Report Merger (openpyxl 1:1 Preservation)
* **Deep Cell Style Cloning**: Uses our standalone Python 3.14 `openpyxl` engine to merge multiple spreadsheets while preserving custom column widths, font weights, colors, cell alignments, and formulas.
* **All Inventory Reports Collector**: Scans any project folder recursively to find all `_Inventory_Report.xlsx` files and consolidates them into a standardized `All Inventory Reports` folder.

### 5. 🛡️ Do Not Upload Isolator & Residual Collector
* **Quarantine Non-Deliverables**: Isolates reference clips, test shots, and internal studio assets out of delivery packages.
* **Reversible Shift Manifest**: Maintains `.json` transaction journals so any shift or transfer can be undone with a single click.

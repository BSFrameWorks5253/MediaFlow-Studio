# Rule: Mandatory Git Commit After Every Change

## Scope
Applies to all tasks involving file modifications, additions, or deletions.

## Directive
1. Every time work on a feature, fix, or requirement is completed and verified, the AI agent MUST stage all relevant files and execute a Git commit.
2. The commit message must clearly summarize what was done, why, and list the components affected.
3. No task is considered finished until the changes are safely committed.

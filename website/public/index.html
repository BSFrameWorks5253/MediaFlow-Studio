The 8-Stage Production Pipeline

From card ingestion to final report delivery, each stage is isolated, verifiable, and lightning fast.

Workspace Overview & Health Hub

The command center provides instant status on physical storage drives, recent ingestion sessions, active pipeline stages, and global hardware telemetry.

  • Real-time drive space headroom visualization
  • One-click navigation into any pipeline phase
  • Activity logs and deletion audit records

Stage 00 • PV Separator

Atomically bifurcates RAW & JPEG photos from video clips in seconds. Automatically generates deletion audit manifests and verifies file sizes before purge operations.

  • Supports CR2, CR3, ARW, NEF, DNG, JPG, MP4, MOV, MXF
  • Safe purge mode with dual-confirmation safeguards
  • Excel audit manifest export with timestamp verification

Stage 01 • Upload Structure Generator

Generates standardized studio hierarchy trees for client archives, sub-events, and cloud uploads with a single click.

Stage 02 • Photo Status Tagger & Matcher

Matches camera shots against master shooting rosters, identifying selected frames, missing numbers, and category tags.

Stage 05 • Multi-Camera Video Transfer

High-throughput 8 MB chunk streaming engine that copies multi-camera footage directly into synchronized timeline directories.

Stage 07 • Deep-Style Excel Report Merger

Python-powered workbook fusion engine that unites disparate inventory and camera reports while flawlessly preserving styling and formulas.

Production Standalone Tools
